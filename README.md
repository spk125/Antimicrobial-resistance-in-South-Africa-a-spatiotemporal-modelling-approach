# South Africa district-level AMR analysis

This directory contains the analysis code used for the district-level antimicrobial-resistance study. The scripts are snapshots of the existing analysis code
## Contents

- `analysis/`: data preparation, crosswalk adjustment, modelling, ST-GPR estimation, applicability diagnostics, annual-change calculations, priority scoring, and bootstrap rank-stability analysis.
- `figures/`: code used to generate the principal maps, covariate-importance plots, and priority-scoring figure.
